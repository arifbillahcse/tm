# Softorio Workspace

Self-hosted personal productivity, professional development and team management software. Private personal workspaces and shared business workspaces; invitation-only initial release, no mandatory paid integrations.

## Stack
PHP 8.3, Laravel 12, MySQL 8, Blade, Livewire, Alpine.js, Tailwind CSS, PHPUnit and GitHub Actions. Verify compatibility in Phase 2.

## Development
Use develop for integration, feature branches for individual phases and main for stable releases. Documentation only; no runnable application yet. Never commit credentials or real private records.
