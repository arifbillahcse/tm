# Phase 8: focus and time tracking
Personal owner-only workspace. Server timestamps and one active session per workspace, versioned transition requests, one time entry per active segment; paused intervals excluded. Presets 25/90/45/5/15 minutes are editable. Target is advisory: countdown reaches zero, recording continues until pause/stop. No auto-stop, background alarms or automatic Pomodoro cycles. Manual entries use local minute precision, reject ambiguous/nonexistent DST times and future, nonpositive or over-24-hour intervals; corrections and soft deletions preserve prior values and reason. Work/break totals separate; billable is a flag, not an invoice. Reports use completed nondeleted segments clipped to local days, weeks and months. Task linking is optional and private; project integration deferred until Phase 12. Browser timer rendering and concurrent load testing remain outstanding. No new paid services or packages.
