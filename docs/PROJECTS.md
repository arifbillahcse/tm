# Phase 12: project management
Business-only separate project tasks; personal task policies unchanged. Owner/admin can view and manage all workspace projects and finances. Workspace managers can create zero-budget projects and manage projects where assigned project manager; members and managers otherwise need explicit project membership. Workspace role removal/demotion is checked on every request. Managers cannot grant management role or manage higher workspace ranks. Assignees must be active project members. Tasks use versioned assignments and status transitions, cycle-checked dependencies, and immutable completion; approval-required tasks must be submitted and reviewed by a different authorized manager (not submitter or assignee). Milestones require linked tasks completed. Project archive is read-only except authorized status change. Templates contain task titles only. Gantt is date-scaled per current task page; Kanban uses status controls, not drag/drop. Project currency is fixed BDT/USD, amounts decimal; only owner/admin sees amounts or records expenses. Time logs manual, positive, workspace daily cap, not synchronized with personal timers or payroll. Comments and activity are escaped, project-scoped. PDF/PNG/JPEG/TXT files private, 5 MB, 100 per project; no malware scanning, filesystem/database atomicity not guaranteed. No notifications, task deletion, full editing, expense correction, automatic scheduling or production deployment. Browser, accessibility and concurrency tests outstanding.
