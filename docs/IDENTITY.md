# Identity and workspace foundation
Bootstrap the first account from a trusted terminal using php artisan workspace:bootstrap-owner owner@example.com. No public registration. Configure SMTP and HTTPS before using real invitations or resets; never use the log mailer in production because it records links. Invitation links are random, hashed at rest, expire in 48 hours, single use, and bound to the invited email; existing users must sign in. New accounts verify email by possession of the invitation. Personal workspaces are owner-only even if a membership is accidentally added. Business roles: owner can manage roles/remove members/invite admins; admin can invite managers/members; manager has project-management ability; member has view access. All future resources require workspace-scoped policies. TOTP uses standard SHA-1/30 seconds/6 digits and encrypted secrets, hashed single-use recovery codes, replay protection; enroll via manual key. 2FA is optional at this stage. Lost second factor and recovery codes require an audited operational recovery process; no web bypass. Session revocation uses version checks and database session deletion. No global administrator bypass. No production deployment.
