# Personal tasks (Phase 5)
Tasks are limited to the active personal workspace and its owner; team assignment arrives in later phases. CRUD, one-level subtasks, priorities, status, date-only My Day, UTC deadlines, tags, list/Kanban (paginated board), filters, dependency cycle detection and private attachments are included. Kanban status changes use the editor, not drag-and-drop. Deletion is soft; restore and retention tooling are not yet exposed. Recurrence creates the next occurrence after the current due date, using the stored timezone and a unique series/time constraint; monthly uses no-overflow calendar arithmetic. It does not copy attachments, subtasks or dependencies. Scheduler tasks:tick runs every minute when the host runs Laravel schedule:run; reminders record in-app audit activity only, not email/push. Attachment allowlist PDF/PNG/JPEG/plain text, 5 MB, randomized private storage, authenticated download. Browser testing, real scheduler deployment, attachment malware scanning and retention remain production acceptance work.
