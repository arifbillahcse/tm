# Phase 9: Second brain and journal
Unified private note library with eight types: notes, bookmarks, ideas, snippets, prompts, research, journal and decisions. Flat folders, tags, explicit related-note links and backlinks. Markdown textarea and saved preview, with raw HTML stripped and embedded links/images removed; code and prompts escaped. Bookmark URLs are HTTP(S) only, never fetched server-side. Versioned edits retain snapshots and reject stale submissions. Search title/body and filter tags, folder, kind and archive. Single-note JSON export. Private PDF/PNG/JPEG/TXT attachments, maximum 5 MB each and 20 per note; remove before permanent note deletion. No automatic malware scan, WYSIWYG editor, bulk export, folder nesting, revision restore or browser-level verification. No paid services.
