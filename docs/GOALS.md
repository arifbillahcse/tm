# Goals, habits and life roadmap (Phase 7)
Owner-only private workspace. Goal CRUD with lifetime/year/quarter/month horizon, categories, optional deadline, target/actual decimal values and units, status and vision text. Progress is a capped percentage of actual/target; status is user-controlled, not inferred from task completion. Milestone CRUD and same-workspace task links are independent progress indicators; deleting goals retains linked tasks. Vision board is text cards derived from goal vision statements, not image uploads. Daily habits use the timezone fixed at creation, unique habit/local-date check-ins, undo, historical check-ins since creation, no future entries, current and best streaks. Current streak can continue through yesterday until today's opportunity ends. Paused days count as missed days. Reports display live goal/milestone/task counts and habit streaks; weekly/monthly reflections are editable by saving the same normalized period. No historical metric snapshots, AI recommendations, new paid services, or production deployment. Browser acceptance and load testing remain outstanding.
