# 20-phase roadmap
Phase 0: planning completed. Each phase requires documented scope, code review, relevant automated tests, authorization review and status update. Do not mark runtime tests passed without evidence.
| Phase | Deliverable / exit criteria |
|---|---|
| 1 | Repository branches and project documentation committed and verified |
| 2 | Laravel scaffold, locked dependencies, configuration, migrations, CI builds and tests |
| 3 | Auth, invitations, 2FA, workspace roles and cross-tenant denial tests |
| 4 | Responsive accessible shell, dashboard, themes and navigation |
| 5 | Personal task CRUD, recurrence, filters, reminders and task tests |
| 6 | Calendar, events and time blocking with timezone tests |
| 7 | Goals and habits, linked tasks and progress reports |
| 8 | Focus timer, timesheets and duration validation |
| 9 | Notes, journal, folders, backlinks, search and private attachments |
| 10 | Career, courses, certifications, jobs, skills, IELTS and portfolio |
| 11 | Team, attendance, leave, work reports and member permissions |
| 12 | Projects, assignments, boards, milestones, dependencies and approvals |
| 13 | CRM contacts, leads, deals, followups and proposals |
| 14 | Private/business ledger, budgets, payroll and currency-safe reports |
| 15 | Software, infrastructure inventory, monitoring and incident logs |
| 16 | Messaging, notifications and optional free integrations; manual WhatsApp |
| 17 | Deterministic analytics and optional local AI with scoped retrieval |
| 18 | PWA, install, push and restricted offline synchronization |
| 19 | Final security/QA, accessibility, performance and backup restore verification |
| 20 | Owner-approved deployment, TLS, scheduler/queues, backups, monitoring, rollback and docs |
## Milestones
1–4 foundation; 5–9 personal productivity; 10–14 career/business/team; 15–17 integrations and intelligence; 18–20 production readiness. Pilot after Phase 5 only after relevant security checks and private deployment. Commercial SaaS is outside initial scope.
