# Phase 10: Career and learning
Private owner-only career center. Ten record types have explicit status sets and allowlisted details, date and URL validation, versioned edits and revision history. Roadmaps use text milestones; courses have manual progress; certifications record issuer, credential and dates; job applications have manual status and follow-up date; interviews have questions/answers/feedback; CVs are private text versions; portfolio is private record management; IELTS is self-entered section/band/date/target (not official assessment); labs track environment/steps/outcome; contacts are private manual records. Skill matrix uses self-assessed levels 0–5 and target 1–5, gap max(0,target-current). Learning sessions have local dates, optional scoped study record, positive minutes and a 24-hour daily cap. Monthly learning total is independent of focus timesheets to avoid claiming automatic synchronization. No external job scraping, automated applications, CV file generation, public portfolio publishing, exam grading, paid services or production deployment. Browser and load tests remain outstanding.
