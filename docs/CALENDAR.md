# Calendar and daily planner (Phase 6)
Private owner-only personal workspace. Day/week/month calendar grids, events, meetings, focus/break time blocks, linked task blocks, task due dates and planned dates, dashboard schedule, date drag/drop for single events and accessible editor fallback. UTC storage; user-local input and display. Recurrence uses a finite series (2–52 occurrences) computed from original local dates, daily/weekly/monthly with month-end clamping; edit/delete affects whole series, no detached exceptions. No duplicate stored instances or scheduler needed. Conflict checks reject overlaps including future occurrences, allow adjacent boundaries, serialize event and template changes on the workspace row. Templates contain 1–12 same-day nonoverlapping blocks, apply atomically once per local date. No external calendar sync, attendees, invitations, or push notifications. Browser drag/drop, visual and DST edge cases require further acceptance verification. No new paid dependencies.

Review: calendar input dates restricted to 2000–2100. Nonexistent and ambiguous local times are rejected, including repeating events that would shift local wall time or hit ambiguous DST hours. Template block keys are allowlisted. MySQL constraint names explicitly shortened.
